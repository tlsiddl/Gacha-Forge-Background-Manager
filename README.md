# Gacha Forge · 배경 관리자

Gacha Forge의 스토리 장소별 배경 저장 상태를 확인하고, 필요한 배경의 생성을 관리할 수 있도록 돕는 **마리나라 개인 확장 프로그램**입니다.

> 현재 버전: **v0.3.5**  
> 가챠포지 한글화 확장과는 별개의 확장 프로그램입니다.

## 주요 기능

### 1. 장소별 저장 배경 자동 확인
- 스토리 응답에서 장소 정보가 확인되면 저장된 배경 목록을 자동으로 조회합니다.
- 스토리에 포함된 장소와 저장된 이미지 URL을 비교하여 배경 등록 여부를 표시합니다.
- 장소 정보가 변경되면 자동 조회가 이루어지며, 동일한 스토리·장소 조합의 불필요한 중복 조회를 줄였습니다.

### 2. 중복 생성 방지 및 수동 승인
- 이미 저장된 배경이 확인된 장소에서는 중복 생성을 막습니다.
- 저장 배경이 누락된 것으로 확인된 장소에 한해 생성 승인을 요청합니다.
- 승인 직전에 저장 여부를 다시 조회하여 중복 생성 가능성을 줄였습니다.
- 목록 조회에 실패하거나 전체 목록이 비어 있는 경우, 누락으로 단정하지 않고 생성 버튼을 잠급니다.
- **사용자 승인 없이 배경 이미지를 자동 생성하지 않습니다.** 이미지 생성에는 비용이 발생할 수 있습니다.

### 3. 전체화면 관리 창 지원 (v0.3.4)
- 가챠포지 전체화면에서도 배경 관리자 팝업이 표시되도록 처리했습니다.
- 열린 Shadow DOM 환경에서는 실제 렌더링 루트로 팝업과 스타일을 이동합니다.
- 전체화면을 종료하면 관리 창을 일반 페이지로 복귀시킵니다.

### 4. 화면 및 편의 기능
- 컴팩트한 티켓형 UI로 배경 상태와 생성 버튼을 제공합니다.
- 장소명 표시 및 버튼·로딩 애니메이션 관련 보정 기능을 포함합니다.
- 확장 프로그램 내부의 한국어 안내 문구를 존댓말로 작성했습니다.

## 설치 방법

1. 이 저장소의 `manifest.json`과 `extension.js`를 이용하여 마리나라 개인 확장 프로그램으로 설치해 주세요. GitHub 확장 관리자를 사용하시는 경우 이 저장소의 주소를 등록해 주세요.
2. 기존 배경 관리자 확장 프로그램이 설치되어 있다면 중복 실행되지 않도록 먼저 비활성화해 주세요.
3. 확장 설치 및 실행 권한을 확인한 뒤 가챠포지 페이지를 새로고침해 주세요.
4. 가챠포지의 스토리를 진행하면 장소별 저장 배경 상태가 확인됩니다. 누락된 배경에 대해서만 생성 여부를 직접 승인해 주세요.

**별도의 서버 브리지를 설치할 필요는 없습니다.** 기존 Gacha Forge 코드나 `me-speedup.cjs` 파일도 수정하지 않습니다.

## 작동 방식

1. 스토리 응답에서 장소 정보를 읽습니다.
2. 공식 `POST /api/gacha-forge/locations`를 통해 저장된 배경 목록을 확인합니다.
3. 장소와 저장된 배경 정보를 비교해 상태를 표시합니다.
4. 배경 누락이 확인된 경우에만 생성 승인 기능을 제공합니다.
5. 생성 직전 다시 확인한 다음, 사용자가 승인한 배경 생성 요청만 실행합니다.

## v0.3.5 변경 사항

- 퀘스트 확장(Gacha Forge Quest Extension) 창이나 알림이 열려 있을 때, 그 안의 '챕터 4' 같은 글자를 스토리 제목으로 잘못 잡아 장소 표시줄을 끼워 넣던 문제를 고쳤습니다. 다른 확장의 패널(`#gfq-01-panel`, `#gfq-01-toasts`)과 열린 대화 상자 안은 제목 후보에서 제외합니다.

## v0.3.4 변경 사항

- 전체화면 요소 내부로 배경 관리자 팝업을 이동하도록 개선했습니다.
- 전체화면 호스트에 열린 Shadow DOM이 있는 경우, 해당 렌더링 루트에 관리 창과 스타일을 적용하도록 보완했습니다.
- 전체화면 종료 시 기존 페이지로 복귀하도록 처리했습니다.
- 티켓형 UI와 자동 배경 확인, 생성 승인 흐름을 유지했습니다.

## 주의사항 및 제한 사항

- 공식 장소 조회 API는 이미지 URL이 있는 장소만 반환할 수 있습니다. 배경 기능이 비활성화되어 있거나 빈 목록이 반환되면 저장 여부를 판단할 수 없어 생성 기능을 잠급니다.
- 스토리 응답이 아직 갱신되지 않았을 때는 이전 장소 정보가 잠시 표시될 수 있습니다.
- 닫힌 Shadow DOM이나 별도 창·iframe 기반 전체화면에서는 관리 창이 정상 표시되지 않을 수 있습니다.
- 실제 VPS 환경의 인증 및 API 응답에 대한 검증이 완료되지 않은 시험 버전입니다. 설치 후 사용 환경에서 동작을 확인해 주세요.
- 이 확장 프로그램은 전체 페이지 접근 권한을 요청합니다. 설치 전에 소스 코드와 권한을 확인해 주세요.
- 이미지 생성 API 호출로 비용이 발생할 수 있습니다.

## 파일 안내

- `extension.js` — 배경 상태 조회, 생성 승인 및 관리 UI 구현
- `README.md` — 설치와 사용 방법 안내
